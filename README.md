# paastudios.com

Сайт студии PAA Studios: главная со всеми играми, страница на игру, политики
конфиденциальности. GitHub Pages отдаёт корень ветки `main` как есть
(`.nojekyll`), домен — `CNAME`. Сайт на английском; страница Pixtangle есть
ещё на 16 языках приложения («Языки» ниже).

## Как устроено

Страницы собираются из данных скриптом без зависимостей, и собранный HTML
коммитится вместе с исходниками: что лежит в `main`, то и на сайте.

```
src/
  games.mjs        каталог игр — порядок на главной, тексты, цвета, сторы, картинки
  studio.mjs       о студии: заголовок, вступление, принципы
  templates.mjs    шаблоны страниц
  i18n/            языки: en.mjs — подписи интерфейса, остальные — их перевод и тексты игр
content/<игра>/    тела страниц, которые пишутся руками (политика конфиденциальности)
assets/            site.css, логотип, мозаика главной, значки сторов, превью ссылок
<игра>/images/     иконка, скриншоты, иллюстрации и превью ссылки игры
tools/             подготовка картинок (Python + Pillow, превью — ещё Google Chrome)
build.mjs          сборка
```

Собранное — `index.html`, `<игра>/index.html`, страницы из `content/`,
`404.html`, `sitemap.xml`. Руками их не править: следующая сборка перезапишет.

```bash
node build.mjs
```

Сборка падает, если игра ссылается на картинку, которой нет в репозитории.

**Цвета игры — данные, а не CSS.** Карточка на главной, мини-карточка «More
from» и вся страница игры красятся переменными из `theme` её записи в
`games.mjs`, поэтому новая игра стилей не требует. `frame` — украшение
карточки: `grid` (клетки поля) или `stitch` (пунктир-стежок по краю).
Главная и 404 — в цветах студии (`.studio` в `site.css`), светлая или тёмная
по системе.

## Языки

Английский — исходный: подписи интерфейса в `src/i18n/en.mjs`, тексты игр в
`src/games.mjs`. Перевод — файл `src/i18n/<код>.mjs` той же формы: `ui` и под
`games.<slug>` тексты игры (картинки, цвета и сторы остаются из записи игры,
подписи к картинкам идут по порядку). Страница игры собирается на каждом
языке, где у неё есть перевод: английская — `/<slug>/`, остальные —
`/<slug>/<код>/`. Порядок языков и их список — `LOCALE_ORDER` в `build.mjs`;
файла нет — язык пропускается. Не хватает строки интерфейса — сборка
подставит английскую и напишет, какой. Главная, 404 и политики — только на
английском.

Языковые версии связаны для поисковиков: `hreflang` в каждой странице (все
версии и `x-default` на английскую), `og:locale` с альтернативами и те же
связи в `sitemap.xml`. Внизу страницы — переключатель языков. Заголовок,
описание, `keywords` (поле `keywords` игры) и разметка `MobileApplication`
у каждой версии свои.

Правила на странице игры — раздел «How to play»: вступление о жанре, шаги,
примечания, затем отдельно приёмы решения (`rules.tips`) и вопросы с ответами
(`faq`). Это и есть текст под запросы вроде «how to solve shikaku»: отдельных
страниц с правилами нет.

## Ссылки в сторы

У игры в `stores` — `appStore` и `googlePlay` с `url` и `id`. Пока стора нет,
ключа нет, и вместо значка страница пишет «Coming soon to …». Вышла игра —
добавить ключ и пересобрать: значок появится и на главной, и на странице
игры, а `id` App Store включит смарт-баннер Safari.

Ссылки на сторы помечены кампанией — страницей, с которой ушёл игрок: `home`
на главной, `<slug>-<код языка>` на странице игры. App Store — `pt` (код
провайдера аккаунта, `appStoreProviderToken` в `src/studio.mjs`), `ct` и
`mt=8`: App Store Connect → Analytics → Acquisition → Campaigns считает по
`ct` открытия карточки и загрузки (сводно, и кампания видна от пяти
установок). Google Play — `referrer` с `utm_source=paastudios.com`,
`utm_medium=website`, `utm_campaign`: Play Console показывает установки по
меткам, а Firebase пишет источник установки игроку — в BigQuery это
`traffic_source` его событий. В разметке (`sameAs`) — ссылки без меток.
Счётчика посещений на самом сайте нет — в подвале обещано, что сайт не
следит за посетителями.

Значки — официальные: App Store — SVG из маркетинговых ресурсов Apple (тот
же, что в `marketing/raw/brand` репозитория игр), Google Play — PNG с
play.google.com без прозрачных полей. Перерисовывать и перекрашивать их
нельзя; подпись о товарных знаках — в подвале.

## Новая игра

1. Иконка и скриншоты:
   ```bash
   python3 tools/images.py <slug> --icon icon-1024.png --screens 01.png 02.png …
   ```
   Пишет `<slug>/images/icon.webp` и `screen-<n>.webp` в порядке аргументов.
2. Запись в `src/games.mjs` — поля описаны в комментарии в начале файла.
   Картинка героя — три скриншота (`art.phones`) или иллюстрация
   (`art.image`); у правил игры своя иллюстрация (`rules.image`).
3. Политика конфиденциальности на этом сайте — тело в
   `content/<slug>/privacy-policy.html` и строка в `pages`; на чужом —
   просто `privacyPolicy` с полным адресом.
4. Превью ссылок: `python3 tools/og.py` (перерисовывает все, включая студию).
5. `node build.mjs`, посмотреть локально и закоммитить исходники вместе с
   собранным:
   ```bash
   python3 -m http.server 8791
   ```
   Страница 404 локальным сервером не отдаётся — её показывает только GitHub
   Pages, локально она открывается как `/404.html`.

## Картинки

- `tools/art.py` рисует SVG: логотип, мозаику главной, поле Pixtangle,
  нонограмму и пяльцы Stitch Tales — палитрами самих игр. Файлы
  закоммичены, скрипт нужен только чтобы их перерисовать.
- `tools/og.py` — превью ссылок 1200 × 630 (`og.jpg`) headless-Хромом с
  `site.css`. Карточка студии всегда в тёмной палитре, независимо от
  оформления машины.
- `apple-touch-icon.png` — логотип без своих скруглений: маску наложит iOS.
